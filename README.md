# Dry Fire Program: Competence

A four-week, 28-day dry fire program with two drills a day, a par time tracker, day checkoff, and a built-in par timer.

Video demos for each day: [@KingWash1789 on X](https://x.com/KingWash1789)

## Use it
Open the GitHub Pages link for this repo in any browser. To install it as an app:
- iPhone (Safari): Share > Add to Home Screen
- Android (Chrome): menu > Install app
- Desktop Chrome or Edge: install icon in the address bar

After the first visit it works offline. Progress saves in each person's own browser.

Always dry fire with an unloaded gun and no ammunition in the room.
